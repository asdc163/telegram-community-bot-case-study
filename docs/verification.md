# Verification scope

Reviewed for publication: 2026-10-27. Evidence below summarizes historical private records. The commercial bot was not started or exercised for this publication.

| Layer | Recorded evidence | Boundary |
| --- | --- | --- |
| Engineering | Automated regression, type checking, and build records. | Supports recorded checks; does not replace a user's Telegram journey. |
| API authority | Current-owner acceptance and non-owner refusal through Telegram API checks. | Role checks do not demonstrate every client interaction. |
| Telegram client | Selected owner and ordinary-member journeys from earlier rounds. | Some later changes lack a fresh walkthrough; full language/device coverage is not claimed. |
| Transfer | Source runtime shutdown, backup/restore checks, and package-integrity verification. | A prepared transfer does not prove recipient deployment or live operation. |

Not established here: a currently running bot, complete parity with another product, all language and device journeys, physical iOS or Android acceptance, real payments, customer-scale capacity, continuous hosting, adoption, or revenue.

Raw messages, private group names, role identifiers, test counts, logs, screenshots, and transfer-package hashes are intentionally omitted. The public repository is a case study, not a replayable commercial test package.
